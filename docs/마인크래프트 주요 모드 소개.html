마인크래프트 주요 모드 소개

2026-08-10 작성

마인크래프트 모드 설치를 처음하는 사람에게, 어떤 모드를 깔아야 할 지 막막할 때가 있습니다.
많은 모드 중 많이 쓰이는 주요 모드들을 소개합니다. 모드들은 모두 Fabric 모드 로더 기준으로 소개합니다.

Fabric API


다운로드(Modrinth)

대부분의 모드를 실행하기 위해 필요한 API 모드. 다른 모드를 설치하기 위해 필수적으로 설치해야 합니다.


Sodium(소듐)


다운로드(Modrinth)

마인크래프트의 대표적인 최적화 모드입니다.


Iris Shader(아이리스 쉐이더)


다운로드(Modrinth)

쉐이더를 적용시키기 위한 모드로, 위의 Sodium(소듐) 모드가 필요합니다.

Mod Menu(모드 메뉴)


다운로드(Modrinth)

현재 설치된 모드들을 보거나, 모드들의 설정을 변경할 수 있는 모드입니다.

Mod Menu(모드 메뉴)


다운로드(Modrinth)

RAM 사용량을 줄여주는 최적화 모드입니다.
